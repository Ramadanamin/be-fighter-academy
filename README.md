# Be Fighter Academy Website

A responsive Arabic website for **Be Fighter Academy**, a private combat-sports coaching business founded by Ramadan Amin.

The project presents private Boxing, Kickboxing, MMA, Self-Defense, and Fitness coaching for adults and children, with training delivered at the client's home, garden, rooftop, private gym, or compound.

## Live Business Website

Current business site:

https://be-fighter-academy-eg.shams00115.chatgpt.site

## Project Goal

Turn the academy's service into a clear digital customer journey:

**Understand the offer → choose the right program → review packages → check service areas → ask questions → submit lead → continue on WhatsApp.**

## Features

- Arabic RTL responsive layout
- Mobile navigation
- Private-coaching positioning
- Kids and adult training programs
- Pricing / package section
- Service-area section
- Coach introduction
- Interactive FAQ
- Lead-capture form
- Automatic WhatsApp handoff with pre-filled lead details
- SEO-friendly semantic HTML structure
- Lightweight static architecture with no framework dependency

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
- WhatsApp deep-link integration

## Lead Flow

The form collects:

- Name
- Phone
- Trainee type
- Training program
- Area
- Main goal

On submit, JavaScript generates a structured WhatsApp message and opens the conversation with Be Fighter Academy.

## Current Version

This repository is a **code-based rebuild of the current Be Fighter Academy web experience** so the project can be owned, version-controlled, improved, and deployed independently through GitHub.

It is intentionally lightweight and can later be upgraded to React / Next.js and connected to a real CRM or backend database.
