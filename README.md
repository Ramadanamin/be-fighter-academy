# Be Fighter Academy

موقع كابتن رمضان أمين لتدريب الملاكمة والكيك بوكسينج واللياقة برايفت للأطفال والكبار في البيت والجاردن والكمباوند.

الموقع المنشور: https://be-fighter-academy-eg.shams00115.chatgpt.site/

## المميزات

- واجهة عربية وإنجليزية تدعم RTL.
- برامج الأطفال والكبار وباقات الأسرة والمجموعات الخاصة.
- صور توضيحية مولّدة بالذكاء الاصطناعي لتدريب الأطفال في الجاردن، مع توضيح ذلك داخل الموقع.
- تأثيرات عمق ثلاثي الأبعاد مع الماوس وحركة ظهور الأقسام، ودعم تقليل الحركة.
- نموذج استفسار يتواصل عبر واتساب، مع تخزين الطلبات في Cloudflare D1.
- لوحة إدارة العملاء وتسجيل دخول الإدارة.

## التشغيل المحلي

يتطلب Node.js 22.13 أو أحدث وpnpm.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

افتح رابط المعاينة الذي يظهر في الطرفية، عادة http://localhost:5173.

## البناء

```sh
pnpm build
```

المشروع يستخدم React وTypeScript وVinext وCloudflare Workers وD1. ملفات SQL موجودة في drizzle/؛ تحتاج قاعدة محلية أو منشورة لتشغيل حفظ العملاء.

## إعداد الإدارة

الأسماء المطلوبة موجودة في .env.example. لا توجد كلمات مرور أو بيانات عملاء في هذا المستودع. يتطلب CRM_ADMIN_PASSWORD_HASH بصمة PBKDF2 بالصيغة المحددة في app/admin-auth.ts، وليس كلمة مرور كنص.

ملف .openai/hosting.json يحتفظ بمعرّف موقع Sites الحالي. رفع المشروع على GitHub يحفظ الكود؛ تشغيل الموقع المنشور يحتاج إعداد الاستضافة وقاعدة البيانات.
